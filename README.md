# Super Mario Browser Game

A browser-based Super Mario-style game developed using JavaScript, focusing on interactivity, game logic, and user experience.

## 🚀 Technologies
- HTML
- CSS
- JavaScript

## 🎮 Features
- Character movement and controls
- Collision detection system
- Game over and restart mechanics
- Simple physics and animations
- Responsive gameplay experience

## 🌐 Live Preview
https://super-mario-sigma.vercel.app/
## 🎯 Goal
Practice game development concepts such as logic, animation, and user interaction in the browser.

## 🚧 Project Status
Completed — open for improvements and new features.
